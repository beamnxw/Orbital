# Floor plan

```
CHIEF
→ signal deck  |  inbox, threads, archive
→ orbit deck   |  calendar, holds, reminders
→ vault deck   |  invoices, receipts, ledger
→ lens deck    |  scrape, enrich, dedupe
→ forge deck   |  reports, charts, briefs
→ drift deck   |  outreach, follow ups, send queue

CHIEF assigns.
decks execute.
i approve

1 login.
1 profile
```

## Loop

1. You write a brief.
2. CHIEF routes it to one deck. No deck sees the full picture.
3. The deck runs and parks a draft in review.
4. You approve. Memory is written to that deck only.
5. Hold parks the job if the draft is wrong.

## Rules

- CHIEF is the only decision-maker.
- Signal owns inbound. Drift owns outbound.
- Vault is the only deck that books spend.
- Lens never ships a brief. It feeds Forge.
- Nothing leaves the building without approve.
